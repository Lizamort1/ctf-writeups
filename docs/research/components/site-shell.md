# Site shell and typography

Sources: `_includes/sidebar.html` and `_includes/head.html`.

- Profile: local square photograph inside a 132px rounded frame, rendered with `object-fit: contain`; title is `Lizamort1`.
- Sidebar and top bar: Van Gogh artwork in both modes. Foreground text has no shadow; the dark overlay supplies contrast.
- Prose: Source Sans Pro at regular weight. Code retains a monospace font. Deliberate `<strong>` emphasis and headings use semibold.
- Dark mode: increase main, metadata, and side-panel contrast while retaining the reference's subdued background.
- Responsive behavior: avatar shrinks slightly on narrow screens; existing Chirpy navigation remains available.
